## 一、什么是 MiMo Orbit 百万亿 Token 计划？

### 1.1 计划概述

Xiaomi MiMo Orbit 是小米面向**全球高质量 AI 用户**的限时 Token 定向发放活动。核心规则：

- **总量**：100 万亿 Token，30 天内发放完毕，赠完即止
- **费用**：完全免费
- **评估方式**：每份申请人工/系统评估，择优发放
- **目标人群**：真正用 AI 进行创造的开发者、团队和企业

### 1.2 MiMo 模型简介

**Xiaomi MiMo** 是小米自研的大模型系列，V2.5 是最新版本，包含：

- **旗舰推理模型**（MiMo V2.5 Pro）：擅长代码生成、逻辑推导、数学推理
- **多模态模型**：支持文本 + 图像理解
- **语音合成模型**：文本转语音

MiMo API 通过 **OpenAI 兼容协议**提供服务，可直接对接 Claude Code、Cursor、OpenClaw 等主流编程工具，迁移成本极低。

### 1.3 你能获得什么？

评估通过后，你可能获得以下权益之一（或组合）：

| 权益类型 | 说明 |
|---------|------|
| **Token Plan** | 订阅制套餐，可配置到 Claude Code / Cursor 等工具直接使用 |
| **赠金** | 充入开放平台账户余额，用于按量计费的 API 调用 |

具体档位取决于你的申请内容质量和账号状态。

## 三、申请全流程（分步详解）

### 第一步：注册 MiMo API 开放平台账号

在提交申请表单**之前**，先完成平台注册：

1. 打开 [Xiaomi MiMo API 开放平台](https://platform.xiaomimimo.com)
2. 使用**邮箱注册**（重要！不要用手机号注册）
3. 完成邮箱验证

> ⚠️ **关键提醒**：申请表单中填写的邮箱必须与开放平台注册邮箱一致。如果平台账号是用手机号注册的，需要先在账号设置中绑定该邮箱，否则权益无法到账。

### 第二步：填写申请表单

打开申请问卷：[https://s.mi.cn/lAVti3813A](https://s.mi.cn/lAVti3813A)

表单包含以下字段，逐项说明：

#### 邮箱

填写你注册 MiMo API 开放平台时使用的**邮箱地址**。务必确认一致。

#### AI 编程工具（多选）

勾选你实际使用的工具，常见选项：

- ✅ Claude Code
- ✅ Cursor
- ✅ Windsurf
- ✅ 其他（如 Copilot、OpenClaw 等）

> 建议：如实勾选即可，不必全选。评估方更看重你的真实使用场景。

#### 模型系列（多选）

勾选你正在使用或计划使用的模型：

- ✅ Claude 系列
- ✅ MiMo 系列
- ✅ DeepSeek 系列
- ✅ GPT 系列
- ✅ 其他

#### 项目描述（核心字段）

这是**评估权重最高**的字段。填写越详细、项目越具体，通过率和权益档位越高。

**撰写要点**：

1. **描述你的 AI 应用场景**：用 AI 做什么？解决了什么问题？
2. **技术架构**：使用了哪些技术栈？如何编排 AI 工作流？
3. **量化数据**：任务量、效率提升、Token 消耗等具体数字
4. **项目规模**：团队大小、运行时长、产出成果

> 💡 **提示**：评估方会综合判断项目的真实性和技术深度。编造数据或夸大描述可能适得其反。请根据自己的实际情况修改以下示例。

## 五、常见问题 FAQ

**Q：权益有有效期吗？**
A：有。不同权益的有效期以到账提示为准，过期未使用的权益自动失效。到账后请及时使用。

**Q：申请用邮箱和小米 ID 绑定邮箱不一致怎么办？**
A：两种解决方案：
- 方案 A：在 [开放平台](https://platform.xiaomimimo.com) 修改注册邮箱，与申请邮箱对齐
- 方案 B：在 [小米账号中心](https://id.mi.com) 修改绑定邮箱

**Q：个人开发者可以申请吗？**
A：可以。个人开发者、团队、企业均可参与，没有门槛限制。

**Q：Token Plan 和赠金有什么区别？**
A：
- **Token Plan**：订阅制套餐，有固定额度和有效期，适合稳定使用场景
- **赠金**：充入账户余额，按量计费消费，灵活度更高

**Q：可以多次申请吗？**
A：如果首次未通过，可以补充材料后重新提交。已通过的用户不建议重复申请。
